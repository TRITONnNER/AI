# AI

Агент, который учится жить в компьютере с нуля, как человек, впервые севший за
ПК. Только пиксели экрана, стереозвук и возможность нажимать клавиши и двигать
мышь. Ни координат, ни названий клавиш, ни API игры, ни подсказок.

Замысел, инварианты и словарь — в `CLAUDE.md`. Текущая веха — `MILESTONE-0-HARNESS.md`.

## Быстрый старт

```bash
pip install -e '.[dev]'
python -m pytest -q                        # 324 теста, около 45 секунд
python -m harness.cli status               # что готово, что нет и почему — по коду

python -m harness.cli backends             # что доступно на этой машине
python -m harness.cli gen-corpus /tmp/s    # синтетическая сессия с известной истиной
python -m harness.cli verify /tmp/s        # целостность записи
python -m harness.cli replay /tmp/s        # покадрово
python -m harness.cli selfworld /tmp/s     # разделение экранного и мирового слоёв
python -m harness.cli profile --schema     # все настройки таблицей, с единицами
python -m harness.cli devices              # что агент видит и чем управляет
python -m harness.cli babble /tmp/b --compare-truth   # агент открывает своё тело
python -m harness.cli loop /tmp/l --compare-truth     # драйв → цель → пробы → тест
python -m harness.cli bench                # один код по четырём мирам: игра, документ,
                                           # рабочий стол, видео
python -m harness.cli describers           # какие бесплатные сервисы описания настроены
python -m harness.cli plan                 # весь стек до плана: лепет, разведка,
                                           # модель перехода, план, исполнение
python -m harness.cli report /tmp/l        # показатели по журналу рядом со словами
                                           # агента о себе — и они ни на что не влияют
python3 tools/make_figures.py docs/figures # перерисовать картинки по свежим прогонам
```

Без установки: `PYTHONPATH=src python -m harness.cli ...`

## Состояние

Короткий ответ на «что готово» — `docs/STATUS.md`, и он **сгенерирован по коду**:
инварианты берутся из тестов, настройки из схемы, части из наличия модулей и тестов,
а у каждого пункта «чего нет» обязана быть причина. Написанный руками такой список
расходится с кодом на второй неделе, и расхождение не видно. Перегенерировать:
`python -m harness.cli status --tests --md docs/STATUS.md`.

Веха 0 сделана в той части, которая проверяема офлайн, и не закрыта в той,
которая требует живой машины.

Работает и проверено на записи: журнал с дозаписью и цепочкой хешей,
покадровое воспроизведение с промоткой, профиль с двумя хешами и форком ветки,
разделение экранного и мирового слоёв (IoU 0.81 при точности 1.00 в игре, и оно же
работает в браузере, на рабочем столе и в проигрывателе),
маска ввода, СТОП с обрывом внутри одного кадра, сторожевой таймер.

Не проверено, потому что здесь нет ни дисплея, ни звука, ни игры: сам захват
экрана, инъекция ввода в игру, петлевой звук, горячая клавиша СТОПа. Все они
отказываются работать с внятным текстом, а не подсовывают правдоподобные данные —
полный список в `docs/ARCHITECTURE-HARNESS.md`.

Поверх харнесса построен агентский слой: схема настроек с единицами измерения и
пределами (включая память, диск, расход и число карточек), реестр устройств с
раздельными правами «видеть» и «управлять», интерактивный мир, ошибка
предсказания, карточки с происхождением, граф мест без координат, драйвы,
лепет, цели с тестом и бюджетом, библиотека навыков из журнала, контуры с
субсумпцией, размыкатель эффекторов, файрвол восприятия, сон и экземпляры.
Подробно — в `docs/ARCHITECTURE-AGENT.md`.

Четыре самых показательных результата. **Лепет открывает тело с нуля**: без единого
названия клавиши агент находит все 9 отвечающих выходов из 24, все 15 молчащих,
все 8 обратных пар и единственный необратимый — на пяти сидах без ошибок.
**Круг замкнут**: давление драйва ставит цель, пробы её закрывают, невозможная
цель честно бросается по бюджету. И **доменная независимость перестала быть
заявлением**: `harness bench` прогоняет один и тот же код по четырём разным мирам —
игра, документ, рабочий стол, проигрыватель, — и на шести сидах проходят все четыре.
Этот замер стоил двух отброшенных гипотез, ещё двух признаков разделения слоёв поверх
параллакса, трёх исправлений в самой истине и четвёртого состояния у выхода в карте
тела. В игре IoU вырос с 0.54 до 0.81 при точности 1.00, полнота по неподвижному
обрамлению — с 0.50 до 1.00. Всё с числами в `docs/ARCHITECTURE-AGENT.md`.

И **круг дошёл до плана**: модель перехода «(место, действие) → место» строится из
журнала, планировщик ищет по ней цепочку до места, где тест цели пройдёт, а исполнение
сверяет каждый шаг с предсказанием. На подтверждённой части модели доходят все планы —
40 из 40. Замер заодно назвал два предела: шаг, наблюдённый один раз, доходит в
четверти случаев (отсюда порог «наблюдено дважды»), а план из трёх шагов не доходит
никогда — это предел отпечатка вида как представления места, а не планировщика.

**Взгляд стал послойным**, как и задумывалось: система отсчёта × дальность, частоты
обновления по слоям (56% обновлений не делается), фовеация (0.13 элементов от полного
кадра), и **тау вместо расстояния** — время до контакта из скорости расширения, с
медианной ошибкой 3–4% и без единого расстояния. А вот дальность по параллаксу
**не работает**: четыре измеренные попытки, верным находится только тот план, что
совпал с найденным сдвигом. Числа, причины и что нужно дальше — в
`docs/ARCHITECTURE-AGENT.md`; признак `trustworthy=False` и тест не дают на неё
опереться.

Настоящей большой модели нет, но подключить её теперь есть чем: шесть адаптеров к
бесплатным сервисам (Ollama и llama.cpp локально, Google AI Studio, Groq, OpenRouter,
Mistral по сети) с экономией квоты — порог по новизне, побитовый кэш ответов,
уменьшение кадра, цепочка с переходом к следующему при исчерпании лимита. На этой
машине не настроен ни один, и `harness describers` говорит об этом прямо, а не
подсовывает заглушку.

## Правило, из которого следует всё остальное

Никаких молчаливых заглушек. Функция, возвращающая правдоподобное значение
вместо реального, ломает эксперимент незаметно, и это худшее, что может здесь
произойти. Поэтому недоступный backend падает с объяснением, синтетический
корпус помечен синтетическим, а всё непроверенное перечислено списком.
