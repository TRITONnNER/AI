# AI

Агент, который учится жить в компьютере с нуля, как человек, впервые севший за
ПК. Только пиксели экрана, стереозвук и возможность нажимать клавиши и двигать
мышь. Ни координат, ни названий клавиш, ни API игры, ни подсказок.

Замысел, инварианты и словарь — в `CLAUDE.md`. Текущая веха — `MILESTONE-0-HARNESS.md`.

## Быстрый старт

```bash
pip install -e '.[dev]'
python -m pytest -q                        # 107 тестов, около 5 секунд

python -m harness.cli backends             # что доступно на этой машине
python -m harness.cli gen-corpus /tmp/s    # синтетическая сессия с известной истиной
python -m harness.cli verify /tmp/s        # целостность записи
python -m harness.cli replay /tmp/s        # покадрово
python -m harness.cli selfworld /tmp/s     # разделение экранного и мирового слоёв
```

Без установки: `PYTHONPATH=src python -m harness.cli ...`

## Состояние

Веха 0 сделана в той части, которая проверяема офлайн, и не закрыта в той,
которая требует живой машины.

Работает и проверено на записи: журнал с дозаписью и цепочкой хешей,
покадровое воспроизведение с промоткой, профиль с двумя хешами и форком ветки,
разделение экранного и мирового слоёв (IoU 0.74 при полноте 0.99 на пяти сидах),
маска ввода, СТОП с обрывом внутри одного кадра, сторожевой таймер.

Не проверено, потому что здесь нет ни дисплея, ни звука, ни игры: сам захват
экрана, инъекция ввода в игру, петлевой звук, горячая клавиша СТОПа. Все они
отказываются работать с внятным текстом, а не подсовывают правдоподобные данные —
полный список в `docs/ARCHITECTURE-HARNESS.md`.

Кода ИИ нет и в этой вехе не будет: см. «Чего не делать в этой вехе».

## Правило, из которого следует всё остальное

Никаких молчаливых заглушек. Функция, возвращающая правдоподобное значение
вместо реального, ломает эксперимент незаметно, и это худшее, что может здесь
произойти. Поэтому недоступный backend падает с объяснением, синтетический
корпус помечен синтетическим, а всё непроверенное перечислено списком.
