# AI

Агент, который учится жить в компьютере с нуля, как человек, впервые севший за
ПК. Только пиксели экрана, стереозвук и возможность нажимать клавиши и двигать
мышь. Ни координат, ни названий клавиш, ни API игры, ни подсказок.

## Что где лежит

| Файл | Что это |
|---|---|
| `CLAUDE.md` | замысел, инварианты, словарь терминов, архитектура, правила работы |
| `MILESTONE-0-HARNESS.md` | текущая веха: харнесс без единой модели |
| `docs/design-draft/console/` | выгрузка «Пульт агента» из Claude Design — интерфейс исследователя, 12 экранов |
| `docs/DESIGN-REVIEW-CONSOLE.md` | разбор пульта против инвариантов: что ломается, что решить, что защитить |
| `docs/PROMPT-EXPORT-DESIGN.md` | промт для полной выгрузки текстового проектного документа |
| `docs/DESIGN-REVIEW-CHECKLIST.md` | по чему проверяется выгруженный проект |
| `docs/design-draft/` | сюда складывается сама выгрузка, часть за частью |
| `tools/check_design_export.py` | проверка целостности текстовой выгрузки: части, разделы, заглушки |

Кода проекта ещё нет. Сначала проектный документ целиком, потом веха 0.

## Порядок работы с текстовым черновиком

1. Скопировать промт из `docs/PROMPT-EXPORT-DESIGN.md` в чат Claude Design,
   приложив `CLAUDE.md` и `MILESTONE-0-HARNESS.md`.
2. Сохранять каждую часть ответа в `docs/design-draft/part-NN.md` дословно.
3. `python3 tools/check_design_export.py docs/design-draft/` — механическая проверка.
4. Разбор по смыслу против инвариантов — по `docs/DESIGN-REVIEW-CHECKLIST.md`.
