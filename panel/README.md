# Панель исследователя

Спецификация — `PANEL.md`. Здесь только то, как её открыть и откуда в ней числа.

## Открыть

Браузер не отдаёт локальные файлы по `file://`, поэтому нужен локальный сервер — одна
команда из этого каталога:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000/`. Если открыть `index.html` двойным щелчком, панель не
покажет пустой экран, а напишет ровно эти две строки: заготовленное сообщение вместо
загадочной пустоты.

## Клавиши

| Клавиша | Что делает |
|---|---|
| `1`…`7` | экраны: Живое, Состояние, Цели и речь, Память, Журнал, Тело, Опыты |
| `Esc` | вернуться на первый экран, закрыть конфигуратор |
| `P` | конфигуратор профиля поверх любого экрана |
| `g` `w` `e` `s` `f` | накладки на зеркале, по одной; по умолчанию выключены все |

## Откуда числа

Панель читает **один** файл — `fixture.json`, и путь к нему объявлен одной строкой в
`index.html`:

```js
const SOURCE = "fixture.json";
```

Фикстура собирается по настоящей записи:

```bash
# по своему прогону: пишется harness loop, потом собирается фикстура
python3 tools/make_panel_fixture.py

# по любой готовой записи — например по записи с машины оператора
python3 tools/make_panel_fixture.py --session ПУТЬ/К/СЕССИИ
```

У каждой величины в фикстуре есть `source` и `origin`, и панель их показывает под
числом. Происхождений три, и они не смешиваются:

- **живая запись оператора** — снято на настоящей машине: расход места, размер кадра,
  механизм захвата;
- **синтетический прогон** — посчитано по журналу этого прогона: цели, драйвы, ошибка
  предсказания, карта тела, карточки;
- **нет источника** — измерять пока нечем, и вместо числа стоит причина словами. Ноль на
  этом месте означал бы «измерили и получилось нуль», а это другое утверждение.

В нынешней фикстуре без числа две величины из шести: конфабуляция (эпизодов меньше
порога `confab_min_episodes`) и задержка планировщика (контура планировщика в прогоне не
было). Обе называют причину на экране.

Зеркало берёт кадр из отдельной записи и **говорит об этом в подписи**: `harness loop`
кадров в журнал не пишет, а кадр из другой записи — не то, что агент видел в этот момент.

## Проверить

```bash
python3 -m http.server 8000 &
PLAYWRIGHT=$(npm root -g)/playwright/index.mjs \
  node --experimental-default-type=module check.mjs
```

Девять проверок в настоящем браузере: сколько величин видно в покое, какую долю площади
занимает главный объект, переключаются ли экраны с клавиатуры, возвращает ли `Esc`, виден
ли СТОП на каждом экране, выключены ли накладки по умолчанию, открывается ли конфигуратор
поверх экрана, предупреждает ли блок Б про форк журнала, чиста ли консоль.

Статические проверки — `tests/test_panel.py` (запускается вместе с остальными тестами):
подписи ведут к настоящим идентификаторам, источник объявлен один раз, в оформлении нет
градиентов и теней, у каждой строки экрана «Опыты» объявлена единица независимости и `n`.
