# Сюда кладётся выгрузка из Claude Design

Из Claude Design приезжают две разные вещи, и путать их не надо:

- **`console/`** — выгруженные прототипы интерфейса, файлы `.dc.html`. Уже
  лежит «Пульт агента», разбор — в `docs/DESIGN-REVIEW-CONSOLE.md`.
- **части `part-NN.md` в этом каталоге** — текстовый проектный документ,
  выгруженный по промту из `docs/PROMPT-EXPORT-DESIGN.md`. Пока не выгружен.

Проверка `tools/check_design_export.py` относится только ко второму: она читает
`*.md` в этом каталоге и ничего не знает про `.dc.html`.

Одна часть — один файл, по порядку:

```
part-00-manifest.md   манифест из первого ответа
part-01.md            === ЧАСТЬ 1/N === ... === КОНЕЦ ЧАСТИ 1/N ===
part-02.md
...
```

Сохраняйте ответы **дословно**, вместе со строками-маркерами `=== ЧАСТЬ k/N ===`
и `=== КОНЕЦ ЧАСТИ k/N ===`, и с блоком `=== SELF-CHECK ===` в последней части.
Проверка целостности опирается именно на эти маркеры: без них она не сможет
отличить полную выгрузку от обрезанной.

Ничего не правьте руками до проверки. Если модель выдала мусор — пусть мусор
и лежит, его видно скрипту. Аккуратно причёсанный обрывок хуже честного
обрывка: по нему уже не понять, что потерялось.

Проверить:

```
python3 tools/check_design_export.py docs/design-draft/
```

Промт выгрузки — `docs/PROMPT-EXPORT-DESIGN.md`.
Что проверяю по смыслу — `docs/DESIGN-REVIEW-CHECKLIST.md`.
