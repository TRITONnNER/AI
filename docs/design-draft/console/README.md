# Пульт агента — выгрузка из Claude Design

Интерфейс исследователя: то, через что человек смотрит на агента и меняет
условия эксперимента. Это не интерфейс агента — агент экрана пульта не видит
и никогда не получал.

## Файлы

| Файл | Что это |
|---|---|
| `console-v3.dc.html` | последняя версия, 12 экранов — с неё и надо читать |
| `console-v2.dc.html` | предыдущая, 10 экранов |
| `console-v1.dc.html` | первая, 9 экранов |
| `support.js` | рантайм Claude Design, без него `.dc.html` не откроется |
| `render-v1.png` | настоящий рендер v1 в браузере |
| `references/*.png` | десять сгенерированных концепт-картинок, с которых начинался вид |

Открывать так: положить `console-v3.dc.html` и `support.js` в один каталог и
открыть html в браузере. Шрифты тянутся с fonts.googleapis.com — без сети
подставятся системные, разметка не поедет.

`references/` — мудборд, а не документация. Текст на этих картинках
сгенерирован и местами не читается («Маи циклы», «Burdget», «тещущий прогон»),
числа на них ничего не значат. Держим их только как след того, откуда взялся
визуальный язык; если репозиторий станет тяжёлым, это первое, что можно удалить.

## Экраны v3

1. **Живое** — драйвы, настроение, эмоция как модулятор порогов, тело,
   размыкатель, зеркало экрана агента со слоями восприятия, лента ошибки
   предсказания, стек целей, поток речи, связь.
2. **Профиль** — Блок А (параметры, меняются на ходу) и Блок Б (структурные
   переключатели, форкают журнал), разделённые «необратимой границей».
3. **Память** — карточки, убеждения, гипотезы, аффордансы, динамика, связи,
   встречи по трём часам, граф мест, очередь отождествлений.
4. **Журнал** — ветка, временная шкала, скруббер по кадрам, «что видел / чем
   был занят / во что верил», пересборка состояния памяти из журнала.
5. **Тело действий** — карта выходов, маска ввода, прогресс лепета, классы
   эффекта, найденные сочетания, длительности.
6. **Обучение** — хронология сна, сновидение, кривые рефлексов, версии с
   откатом, предупреждение о давней сверке с реальностью.
7. **Эксперименты** — шесть метрик, сравнение прогонов, детектор чистоты
   абляции.
8. **Экземпляры** — параллельные жизни, очередь слияния свидетельств.
9. **Наблюдение** — человек за рулём, предсказание следующего шага человека,
   журнал перехватов, совместное управление, вопросы от агента.
10. **Устройства** — источники захвата, права «видеть» и «управлять» по
    отдельности, разбор задержки до действия.
11. **Стенд** — свой набор панелей на одном экране.

Разбор по инвариантам — `docs/DESIGN-REVIEW-CONSOLE.md`.
