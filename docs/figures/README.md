# Картинки

Все шесть рисуются по настоящим прогонам, а не по придуманным числам:

```bash
python3 tools/make_figures.py docs/figures
```

Скрипт запускает интерактивный мир, лепет, разделение слоёв и граф мест заново, и
числа в подписях берутся из этих прогонов. Если что-то в коде испортится, картинка
испортится вместе с ним — поэтому её можно использовать как отчёт, а не как
иллюстрацию.

| Файл | Что показывает |
|---|---|
| `1-mir.png` | что агент получает: кадры интерактивного мира до и после действий |
| `2-sebya-i-mira.png` | 0.6: найденный экранный слой против истины из отладочного потока |
| `3-oshibka-predskazaniya.png` | ошибка предсказания, всплески, сравнение с опорным уровнем |
| `4-lepet.png` | как открывается тело и карта тела после лепета |
| `5-graf-mest.png` | граф мест: узлы-отпечатки и рёбра-времена |
| `6-chto-sdelano.png` | состояние проекта по всем частям, включая отсутствующие |

Две вещи, которые на картинках нарисованы по истине из отладочного потока, а не по
тому, что видит агент, — и подписаны как таковые: истинная маска интерфейса на
второй картинке и рамка исчезнувшей панели на первой. Агенту эти данные
недоступны; картинки делаются для исследователя.

Раскладка узлов на графе мест произвольна. В графе мест координат нет вообще —
только отпечаток вида и время прохода, — поэтому положение узлов на картинке
получено силовой раскладкой по временам рёбер и ничего не значит само по себе.
