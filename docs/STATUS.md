## Чего нет и почему

| Чего нет | Почему |
|---|---|
| Живая запись с экрана | нет дисплея в этом окружении |
| Инъекция ввода в игру | нет /dev/uinput и нет игры |
| Петлевой звук и горячая клавиша СТОПа | нет звукового устройства |
| Видеокодек для кадров | нет ffmpeg; предел шардов измерен — 106 ГиБ/час на 1080p |
| Ответ настоящей большой модели | адаптеры есть, ни один сервис здесь не настроен |
| Обученные сети, weights/ | предсказатель аналитический; обучение не начато |
| Планы длиннее двух шагов | отпечаток вида склеивает разные состояния мира: 0 из 13 доходят |
| Навык как шаг плана | переходы модели ключуются одиночными действиями |
| Слои восприятия отдельными контурами | PerceptionLayer из архитектуры не реализован; ручки помечены planned |
| Разделение слоёв там, где камера не движется вовсе | остаётся слабейший признак; меняющееся обрамление находится на 0.38–0.54 |
