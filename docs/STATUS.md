## Чего нет и почему

| Чего нет | Почему |
|---|---|
| Независимых наблюдений для утверждений о разделении слоёв | маска истины побитово одинакова при любом сиде во всех пяти доменах, поэтому шесть сидов дают одно наблюдение, а не шесть. Независимых единиц пять — по числу доменов, — и медиана IoU на них 0.667, а не 0.97. Больше единиц даст только живая запись (MEASUREMENT.md, разделы 2 и 3) |
| Живых записей с настоящего экрана | приёмка готова (`harness ingest`, `harness bench-live`), записей нет: в контейнере нет дисплея. Это задача оператора, TASK-03 часть 2. До них любое число разделения слоёв — согласие кода с самим собой |
| Свёртки насыщенных классов в сводку | закладки, карантин, ранжирование и понижение сделаны (TASK-12, часть 2): ранг считает обращения и ненасыщенность, понижение идёт через закладки, карантин агенту недоступен. Чего нет — предложения свернуть насыщенный класс в сводку с тремя типичными примерами и двумя выбросами: `sigma` как сигнал сжатия в ранг входит, но отдельной операции свёртки нет (`STORAGE.md`, раздел 4a) |
| Замера конфабуляции на настоящем агенте | механизм сопоставления работает, но числа нет и не должно быть: реплики планировщика в прогонах ставятся вручную, контура, который объясняется, ещё нет, а эпизодов в корпусе меньше порога `confab_min_episodes`. Прежде здесь стояло «67 %», полученное с шести объяснений одного эпизода, и это проходило как результат (TASK-12, часть 3) |
| Наследования между линиями на деле | манифест и список утечек есть, `as_testimony` объявлен режимом по умолчанию, но ни одна подсистема ещё не умеет загружаться из чужой линии: все девять пунктов манифеста поддерживают только fresh |
| Живая запись с экрана | нет дисплея в этом окружении |
| Инъекция ввода в игру | нет /dev/uinput и нет игры |
| Петлевой звук и горячая клавиша СТОПа | нет звукового устройства |
| Видеокодек для кадров | нет ffmpeg; предел шардов измерен — 106 ГиБ/час на 1080p |
| Ответ настоящей большой модели | адаптеры есть, ни один сервис здесь не настроен |
| Обученные сети, weights/ | предсказатель аналитический; обучение не начато |

По 25 прогонов на метод: баланс 0.49 / 0.50 / 0.54 при случайном 0.33 — то есть частично находится, но разброс 0.14–0.20 и отдельные прогоны от 0.25 до 0.83. Различить методы по такому разбросу нельзя. Нужно послойное разделение движения: совместная оценка «где какой слой» и «как он движется». Таблицы — в harness.vision.flow |
