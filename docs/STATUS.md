## Чего нет и почему

| Чего нет | Почему |
|---|---|
| Живая запись с экрана | нет дисплея в этом окружении |
| Инъекция ввода в игру | нет /dev/uinput и нет игры |
| Петлевой звук и горячая клавиша СТОПа | нет звукового устройства |
| Видеокодек для кадров | нет ffmpeg; предел шардов измерен — 106 ГиБ/час на 1080p |
| Ответ настоящей большой модели | адаптеры есть, ни один сервис здесь не настроен |
| Обученные сети, weights/ | предсказатель аналитический; обучение не начато |
| Оставшиеся 6 % планов | планы от трёх шагов доходят 224 из 239 на восьми сидах. Провалы — там, где расхождение предсказаний нашлось, но разделить его не удалось ни по яркости, ни по одной ячейке: делить нечем, и выдумывать порог нельзя |
| Второе деление одного места | место делится один раз: `splits` держит один порог на место. Состояние мира, различимое двумя признаками сразу, разделится только по первому |
| Навык как шаг плана | переходы модели ключуются одиночными действиями |
| Слои восприятия отдельными контурами | PerceptionLayer из архитектуры не реализован; ручки помечены planned |
| Разделение слоёв там, где камера не движется вовсе | остаётся слабейший признак; меняющееся обрамление находится на 0.38–0.54 |
| Дальность (ближний/средний/дальний план) по параллаксу | четыре измеренные попытки: верным находится только план, совпавший с найденным сдвигом. Нужен настоящий оптический поток — пирамида масштабов, субпиксельная точность, регуляризация с разрывами. Таблица замеров в harness.vision.layers |
| Разделение слоёв в мире с глубиной | метод стоит на допущении «у мира одно движение»; при трёх планах признаки расходятся на 91 % пикселей, и сторож расхождений это показывает |
